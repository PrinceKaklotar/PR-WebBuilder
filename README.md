# 🌐 PR WebBuilder  
🚀 AI-Powered Website Builder

PR WebBuilder is a full-stack web application that allows users to generate, edit, and publish websites using simple text prompts. It combines AI, real-time preview, and a credit-based system to deliver a powerful website creation experience.

---

## ✨ Features

- Generate complete websites from text prompts  
- Modify websites using conversational AI  
- Live preview of generated websites  
- Version control with rollback functionality  
- Secure authentication system  
- Credit-based usage with Stripe payments  
- Publish websites instantly  

---

## 🛠️ Tech Stack

Frontend:
- React  
- TypeScript  
- Tailwind CSS  

Backend:
- Node.js  
- Express  

Database:
- PostgreSQL  
- Prisma ORM  

Other:
- Better Auth  
- Stripe (Payments & Webhooks)  
- AI APIs (OpenRouter / LLMs)

---

## 🧠 How It Works

1. User enters a prompt  
2. AI generates a complete website  
3. Code is stored and versioned  
4. User can edit via chat-based prompts  
5. Website preview updates in real-time  
6. Users can publish or rollback versions
